# StealthGuard Benchmark: Code and Data Generator

Code and data for the manuscript *"StealthGuard: A Physics-Informed
Framework and Realistic Benchmark for Detecting Stealth Cyber-Attacks
on Power Grid State Estimation"* (IET Cyber-Physical Systems: Theory &
Applications, submission CPS-2026-10-0104).

Public repository: https://github.com/paradoxfxx/StealthGuard-benchmark

## Contents

- `sim/` — quasi-steady-state simulation platform for the IEEE 39-bus
  New England system: DC measurement model with topology changes
  (`grid39.py`), stochastic daily load curves with bus-level
  autoregressive drift, natural disturbances (load step / generator
  trip / line outage) and three attack types (stealth FDIA, replay,
  random false data) as onset-anchored episodes (`scenarios.py`,
  `run_sim.py`).
- `models/` — the two-branch detector (temporal-difference stem,
  plug-in encoders: BiGRU / LSTM / 1-D CNN / Transformer / selective
  SSM / GRU+SSM) and the conditional generative models (CDDM, WGAN-GP).
- `scripts/` — full pipeline: dataset generation (`sweep.py`),
  detector training/evaluation (`train_detector.py`, one JSON per run
  into `results/`), baselines (`eval_classical.py`,
  `baselines_external.py`), attack-axis sweeps (`eval_attack_axis.py`,
  `eval_ramp.py`), the static-load control dataset
  (`gen_static_control.py`), subtype aggregation
  (`backfill_subtype.py`), and table generation.
- `results/` — evaluation outputs (`*.json`) for every run reported in
  the manuscript, including `subtype_metrics.json` (per-subtype
  recalls from saved logits) and `ablation_precision.json` (FDIA
  precision of the ablation variants).
- `tables_en/` — the six English tables used in the manuscript,
  regenerated from `results/*.json` by `scripts/gen_tables_en.py`.

## Reproducing the tables

All tables in the manuscript are generated from this package:

```bash
python scripts/gen_tables_en.py     # writes tables 1-6 into tables_en/
python scripts/gen_tables.py        # the same tables with Chinese headers
```

The numbers are means over seeds {0, 1, 2} with population standard
deviations where the manuscript marks "±"; single runs elsewhere.
(As of this snapshot, `results/` contains the full evaluation outputs;
`sweep.py` schedules the underlying training runs. FDIA precision in
the ablation table is computed from the saved logits and stored in
`results/ablation_precision.json`.)

## Environment

See `requirements.txt`. All random seeds are fixed in the scripts;
splits use disjoint seed ranges. Reported runs used a single RTX 5090D
32 GB GPU, serially (about 25 GPU-hours for the full grid).
